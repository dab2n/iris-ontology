# IRIS · Meeting Ontology

회의 한 건을 사람·논의·결과의 관계 그래프로 정리해 보여 주는 화면입니다.
질문을 적으면 그래프를 따라간 경로와 함께 답을 보여 줍니다.

- 전시용 공개본입니다. 전사문에 나온 이름·브랜드는 모두 가명으로 바꿔 두었습니다.
- AI 탐색은 발표자 노트북에서만 돌아갑니다. 여기서는 규칙 기반 탐색으로 답합니다.
- 왼쪽 위 X · Y · Z 를 누르면 그 축을 따라 카메라가 훑습니다 (키보드 X · Y · Z).
- 화면 위에서 모두 · 요소 · 관계 를 바꿔 맵 구조를 볼 수 있습니다.
- 40초 동안 아무 조작이 없으면 맵이 스스로 설명하는 전시 모드로 들어갑니다.
- `H` 키로 왼쪽 패널을 열고 닫습니다.
